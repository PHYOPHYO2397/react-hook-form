# 📝 React Login Form with Validation (React Hook Form + Zod)

This is a simple React login form using **React Hook Form** and **Zod** for schema-based validation. It includes fields for:

- 名前 (Name)
- メールアドレス (Email)
- パスワード (Password)

Validation is managed through `zodResolver` and a Zod schema.

---

## 📦 Features

- ✅ Type-safe form validation with Zod
- ✅ Controlled form with `react-hook-form`
- ✅ Error messages in Japanese
- ✅ Minimal and clean UI
